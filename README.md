## À Table! 프랑스 식사 예절 게임

프랑스 식사 예절을 한국어와 프랑스어로 배우는 모바일 친화형 웹게임입니다.

## 바로가기

- 공개 웹사이트: https://juajua090921-jpg.github.io/a-table-etiquette/
- GitHub 저장소: https://github.com/juajua090921-jpg/a-table-etiquette

## 다른 기기에서 이어서 작업하기

1. 이 저장소 주소를 열고 같은 GitHub 계정으로 로그인합니다.
2. Codex 데스크톱 앱에서 같은 OpenAI 계정으로 로그인합니다.
3. 기존 Codex 작업은 데스크톱 앱의 Codex 목록에서 같은 대화를 엽니다.
4. 다른 컴퓨터에서 코드를 직접 수정할 때는 저장소를 Clone한 뒤 작업하고 GitHub에 Push합니다.
5. main 브랜치에 반영되면 GitHub Actions가 공개 웹사이트에 자동 배포합니다.

## 현재 구현된 기능

- KO / FR 언어 전환
- 6개 프랑스 식사 예절 미션
- 오답 시 정답 안내 후 다음 미션 진행
- 3회 경고 실패 시스템
- 웨이터 유래 힌트
- 이용자와 웨이터 전신 캐릭터
- 모바일 화면 반응형 레이아웃

## 로컬 실행

npm install
npm run dev

브라우저에서 http://localhost:3000/a-table-etiquette/ 를 엽니다.
